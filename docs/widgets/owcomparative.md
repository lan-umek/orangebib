# Comparative Analysis

> Side-by-side metric comparison of groups.

```{figure} ../_static/img/owcomparative.png
:alt: Comparative Analysis
:class: widget-screenshot

The Comparative Analysis widget.
```

## Overview

Compares groups defined by a column on a set of headline metrics (documents,
citations, collaboration…), giving a compact group-by-metric comparison table —
a quick descriptive overview before deeper association/inference testing.

## Inputs
- **Data** (`Table`) — bibliographic data.

## Outputs
- **Comparison** (`Table`) — metrics by group.

## Controls
- **Group by column** — the grouping variable.
- **Top N groups** — limit to the largest groups.

**Actions:** `Compare`.
