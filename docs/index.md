# Orange3-Biblium

Bibliometric & scientometric analysis widgets for
[Orange Data Mining](https://orangedatamining.com/), powered by the
[Biblium](https://github.com/lan-umek/biblium) engine.

Orange3-Biblium turns Orange's visual canvas into a complete bibliometric
workbench: load and enrich data, compute counts and indicators, analyse
citations and networks, classify by methodology / SDG, model topics, and
publish interactive reports — all without writing code.

## At a glance

- **81 widgets** organised by analysis stage.
- Imports from Scopus, Web of Science, OpenAlex, PubMed, Dimensions, Lens,
  SICRIS/COBISS and 30+ formats.
- OpenAlex API querying and DOI enrichment.
- Co-occurrence, citation, coupling, collaboration and field networks.
- Reports and a one-click interactive HTML dashboard.
